FAQ

What is HTTP 402?
HTTP 402 Payment Required is a status code reserved for digital payment systems. It signals that payment is needed before the server will fulfill the request.
What currency is used?
USDC on Solana mainnet. Payments are verified on-chain using the transaction signature and memo.
Do I need an account?
No. There are no accounts, no API keys, and no signup. You just need a Solana wallet with USDC.
Is my identity tracked?
No. blind402 stores no user identity. There are no cookies, sessions, or tracking.
How long is a quote valid?
Quotes expire after 60 seconds. You must pay and submit the payment proof within this window.
Can I reuse a payment?
No. Each transaction signature can only be used once. Replay attacks are blocked.
