HTTP 402 Protocol

Pay Per Request. Zero Friction.

Gate API access behind Solana USDC micropayments. No accounts. No API keys. No identity. Just pay and access.

View on GitHub Read Protocol

How it works

1

Request

Client calls any protected API endpoint without authentication

2

Quote

Server responds with HTTP 402 and a signed payment quote

3

Pay

Client transfers USDC on Solana with payment ID in memo

4

Access

Client retries with proof. Server verifies on-chain and returns data

Example

Terminal
# Request without payment - returns 402 with quote curl https://api.blind402.com/v1/data # After paying USDC with memo "BLIND402:{payment_id}" curl https://api.blind402.com/v1/data \ -H "X-BLIND402-QUOTE: {quote_json}" \ -H "X-BLIND402-PAYMENT: {tx_signature}" # Returns protected data
