blind402

HTTP 402 Payment Required for APIs

Gate API access behind Solana USDC micropayments. No accounts. No API keys. Pay per request.

What it does

blind402 implements HTTP status code 402 for real-world use. Clients pay for each API request using USDC on Solana. The server verifies payment on-chain before returning the response. There is no authentication, no rate limiting by identity, and no stored user data.

How it works

  1. Client requests a protected endpoint
  2. Server responds with HTTP 402 and a payment quote
  3. Client transfers USDC on Solana with the payment ID in the memo
  4. Client retries the request with the quote and transaction signature
  5. Server verifies payment on-chain and returns the resource

Example

# Request without payment
curl https://api.blind402.com/v1/data

# Returns 402 with quote

# After paying, retry with headers
curl https://api.blind402.com/v1/data \
  -H "X-BLIND402-QUOTE: {quote_json}" \
  -H "X-BLIND402-PAYMENT: {tx_signature}"
