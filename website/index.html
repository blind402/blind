FAQ

HTTP 402 Payment Required is a status code reserved for digital payment systems. It signals that payment is needed before the server will fulfill the request. blind402 implements this using Solana USDC transfers.
What is HTTP 402?
USDC on Solana mainnet. Payments are verified on-chain using the transaction signature and memo.
What currency is used for payment?
No. There are no accounts, no API keys, and no signup. You just need a Solana wallet with USDC to make payments.
Do I need to create an account?
No. blind402 stores no user identity. There are no cookies, sessions, or tracking. The only data retained is transaction signatures for replay protection, which expire after 15 minutes.
Is my identity tracked?
Quotes expire after 60 seconds. You must pay and submit the payment proof within this window.
How long is a quote valid?
No. Each transaction signature can only be used once. Replay attacks are blocked.
