blind402

HTTP 402 Payment Required for APIs

blind402 is a protocol for gating API access behind Solana USDC micropayments. Clients pay per request. No accounts. No API keys. No authentication.

What is HTTP 402?

HTTP 402 Payment Required is a status code reserved for digital payment systems. It indicates that a request cannot be fulfilled until the client provides payment. blind402 implements this status code using Solana USDC transfers.

How It Works

  • Client requests a protected endpoint
  • Server responds with HTTP 402 and a payment quote
  • Client transfers USDC on Solana with a memo containing the payment ID
  • Client retries the request with the quote and transaction signature in headers
  • Server verifies the payment on-chain and returns the resource

Example

Request without payment:

curl https://api.blink402.com/v1/data

Response (402 Payment Required):

{
  "quote": {
    "protocol": "blind402",
    "version": 1,
    "mint": "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
    "recipient": "...",
    "amount_atomic": 1000,
    "expires_at": 1767426853733,
    "payment_id": "96b73a2d...",
    "tier": 0
  },
  "quote_token": "9883c254..."
}

After paying USDC with memo BLIND402:<payment_id>, retry with headers:

curl https://api.blink402.com/v1/data \
  -H "X-BLIND402-QUOTE: {entire quote JSON}" \
  -H "X-BLIND402-PAYMENT: <tx_signature>"

Privacy

blind402 stores no user identity. There are no accounts, sessions, or tracking. The only data retained is transaction signatures for replay protection, which expire after 15 minutes.
